Objectif Prime

Perdre du poids, mais entre amis

Next.jsSupabaseTailwind

Défiler

Les applications de suivi existantes font tout, sauf la seule chose qu'on voulait avec des amis : se comparer entre nous, simplement, sans partager nos données au monde entier.

Conception, développement web, schéma Supabase, version iOS avec Capacitor.

01

Le quotidien en une page

Onboarding (taille, poids, âge, objectif, date cible), tableau de bord du jour : poids, calories ingérées et dépensées, bilan, pas. Courbe d'évolution du poids, journal alimentaire branché sur Open Food Facts (recherche et code-barres), activités sportives avec estimation des calories par MET.

  • Next.js 16 App Router, Server Actions
  • Tailwind CSS 4
  • Graphiques Recharts
02

Le groupe

Groupes privés rejoints par code d'invitation, classement sur le pourcentage perdu plutôt que les kilos — pour que ce soit juste entre gabarits différents. Politiques de sécurité par ligne dans Supabase : on ne voit que les groupes dont on fait partie.

  • Supabase Auth + Postgres + RLS
  • Déploiement Vercel
  • Version iOS encapsulée avec Capacitor

Ce que ça a donné

  • 3sources de données : saisie, Open Food Facts, app Santé
  • 2plateformes : web et iOS
