EcoTracker

Une naturothèque pour la biodiversité

MongoDBAPI RESTPython

Défiler

Une naturothèque : une bibliothèque du vivant, où chacun ajoute ce qu'il observe. EcoTracker collecte des observations d'espèces, les nettoie, les stocke et les montre sur une carte des espaces naturels.

Mon rôle

Données et backend : collecte d'observations via API, modélisation MongoDB, nettoyage, cartographie ; contribution au cahier des charges et au pilotage (Jira, Notion, Gantt).

Stack

  • Python
  • MongoDB
  • API REST
  • JavaScript
  • Jira · Notion

Des données hétérogènes

Observations issues d'API externes, de fichiers CSV et JSON, de saisies utilisateurs. Un pipeline de nettoyage et de transformation avant stockage dans MongoDB, puis une carte interactive des espaces et des espèces observées.

  • Collecte via API REST
  • Base MongoDB
  • Carte interactive
