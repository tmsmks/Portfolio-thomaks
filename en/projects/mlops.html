From notebook to deployed service, reproducibly

A model that works on my laptop is useful to no one. This project installs the discipline: versioned data, tracked experiments, a service that rebuilds itself on every commit.

Full pipeline setup, from data versioning to cloud deployment.

01

Four stages, one graph

prepare → train → evaluate → serve, described in dvc.yaml with their parameters. DVC only reruns what changed; data and models live on Google Cloud Storage; every training run is tracked in MLflow.

  • DVC pipeline and GCS remote
  • MLflow tracking
  • Centralised parameters (params.yaml)
02

Deliver automatically

FastAPI service containerised with Docker, a GitHub Actions workflow that reproduces the pipeline, evaluates, and deploys to Google Cloud using repository secrets.

  • Dockerfile
  • GitHub Actions CI/CD
  • Google Cloud deployment

What came out of it
