Objectif Prime

Lose weight, but with friends

Next.jsSupabaseTailwind

Scroll

Existing tracking apps do everything, except the one thing we wanted among friends: compare ourselves with each other, simply, without sharing our data with the whole world.

My role

Design, web development, Supabase schema, iOS version with Capacitor.

Stack

  • Next.js 16
  • TypeScript
  • Tailwind CSS 4
  • Supabase
  • Open Food Facts API
  • Recharts
  • Capacitor
  • Vercel

Links

  • github.com/tmsmks/objectif-prime-web ↗
01

The day on one page

Onboarding (height, weight, age, goal, target date), daily dashboard: weight, calories in and out, balance, steps. Weight curve, food journal connected to Open Food Facts (search and barcode), sports activities with MET-based calorie estimates.

  • Next.js 16 App Router, Server Actions
  • Tailwind CSS 4
  • Recharts charts
02

The group

Private groups joined with an invitation code, leaderboard on percentage lost rather than kilos — so it's fair between different builds. Row-level security policies in Supabase: you only see the groups you belong to.

  • Supabase Auth + Postgres + RLS
  • Vercel deployment
  • iOS version wrapped with Capacitor

What came out of it

  • 3data sources: manual entry, Open Food Facts, Health app
  • 2platforms: web and iOS
