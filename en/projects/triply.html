Triply

Dream it. Plan it. Live it.

FlutterFirebaseGoogle Maps

Scroll

A group trip is a WhatsApp group overflowing, three spreadsheets and a scanned passport lost among the photos. Triply puts everything in one place, for everyone, at the same time.

My role

Flutter architecture, Firestore data models, map and geolocation, real-time sync.

Stack

  • Flutter 3.9
  • Dart
  • Firebase Auth · Firestore · Storage
  • Google Maps · Places API
  • Riverpod
  • GoRouter
  • Freezed

Links

  • github.com/tmsmks/triply ↗Private repository — code on request
01

Plan together

Create a trip with dates, budget and destination (Google Places autocomplete with coordinates), invite companions by email, day-by-day planning with geolocated places, a Google Map of all your trips.

  • Riverpod for reactive state
  • GoRouter and declarative navigation
  • Immutable models generated with Freezed
02

Share the rest

Multi-currency budget with automatically updated balance, checklist split between participants, documents (tickets, bookings) stored in Firebase Storage, collaborative photo album. Full interface in French and English, switched on the fly.

  • Firestore with per-trip security rules
  • Real-time sync between participants
  • iOS, Android, web and macOS

What came out of it

  • 4platforms from a single codebase
  • 2languages, switched without restarting
  • 6modules: plan, budget, checklist, documents, photos, map
